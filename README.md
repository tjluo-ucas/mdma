# MDMA bilingual course site

Bilingual Jekyll site for **Management Decision Modeling & Analysis (MDMA)**, designed around a problem-oriented learning loop:

> management problem → decision frame → model → solution → verification → recommendation → implementation review

The site preserves the approved 2026 intensive-course baseline while adding a research-grounded knowledge map spanning spreadsheet engineering, decision analysis, optimization, simulation, robust/stochastic optimization, and data-driven prescriptive analytics.

## Verify locally

```bash
ruby scripts/check_site.rb
ruby scripts/preview_build.rb
```

## Public boundary

Cases are summarized by decision type and evidence expectations. Protected case exhibits, frozen parameters, instructor workbooks, solutions, hidden tests, student submissions, peer ratings, and grades are excluded.
